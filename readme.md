# 🎡 CircleApp (Exam Project)

Проект интерактивного кругового календаря исторических дат со встроенным слайдером событий. Разработан на React, TypeScript и оптимизирован под быструю сборку с помощью Vite.

🔗 **Демо-версия сайта:** [circleappgm.netlify.app](https://circleappgm.netlify.app/)

---

## 🚀 Технологический стек

* **Frontend:** React 18+, TypeScript
* **Сборщик:** Vite (мигрировано с Webpack)
* **Анимации:** GSAP (GreenSock Animation Platform) + `@gsap/react`
* **Слайдер:** Swiper.js
* **Стили:** SCSS / Sass

---

## 🛠️ Инструкция по локальному запуску

Для успешного запуска проекта на вашем компьютере должен быть установлен **Node.js** v18 или выше.

### 1. Клонирование репозитория

Склонируйте проект с помощью SSH-ключа:
```bash
git clone git@github.com:TheSkyLand/Exam.git
```
*Или скачайте проект напрямую в виде ZIP-архива с веб-интерфейса GitHub.*

### 2. Установка зависимостей

Перейдите в корневую папку проекта и установите все необходимые пакеты:
```bash
npm install
```

### 3. Запуск сервера разработки

Запустите локальный сервер. Проект настроен на автоматическое открытие в браузере:
```bash
npm run dev
```

### 4. Просмотр проекта

После запуска сервера откройте браузер и перейдите в адресную строку по следующему пути:
```bash
http://localhost:3000/test
```

---

## 📦 Сборка проекта (Production)

Для создания оптимизированнойproduction-версии приложения выполните команду:
```bash
npm run build
```
Финальные файлы будут сгенерированы в папке `dist/`, которая полностью готова к деплою на такие платформы, как Netlify или Vercel.
